## Метрики модели

- M01 Delivery_Speed_Score - Оценка средней скорости доставки заказов., вес 0.15
- M02 Flower_Freshness_Index - Индекс свежести используемых цветов, на основе отзывов и поставщиков., вес 0.20
- M03 Supplier_Diversity_Ratio - Разнообразие поставщиков цветов для снижения зависимости., вес 0.10
- M04 Customer_Service_Responsiveness_Score - Оценка оперативности и качества ответов службы поддержки., вес 0.15
- M05 Florist_Expertise_Index - Индекс квалификации и опыта флористов компании., вес 0.15
- M06 Website_Conversion_Capacity - Эффективность сайта в конвертации посетителей в покупателей., вес 0.10
- M07 Logistics_Optimization_Ratio - Оценка эффективности логистических маршрутов и управления доставкой., вес 0.05
- M08 Refund_Rate_Penalty - Штраф за высокий процент возвратов и отмен заказов., вес 0.05 (штрафная)
- M09 Seasonal_Supply_Risk - Риск дефицита определенных цветов в зависимости от сезона., вес 0.05 (штрафная)

## Как проверить расчет

1. Откройте SCORING_MODEL.csv - зафиксированные веса.
2. Откройте RUBRICS.csv - якоря баллов 0/2/4/6/8/10.
3. Откройте SCORE_MATRIX.csv - балл каждой ячейки со статусом и ссылкой на источник.
4. Запустите python calculate_ranking.py - результат должен совпасть с RANKING_RESULTS.json.

**Относится ли вывод ко всему рынку?**
Нет. Вывод действует внутри зафиксированной выборки из 3 участников и в пределах опубликованной методологии на 2026-09-17.

**Что означает балл 70.00?**
Это сумма подтвержденных взвешенных вкладов, а не доля рынка и не оценка рекламного характера. Проверить можно по исходным CSV и скрипту расчета.
